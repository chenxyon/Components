# WIFI Manager 组件接线说明

## 硬件接线概述

WIFI Manager 组件使用 ESP32 内置的 WIFI 模块，**不需要额外的硬件接线**。WIFI 模块与 ESP32 芯片内部集成，所有通信引脚已在芯片内部连接。

---

## ESP32 芯片 WIFI 模块引脚说明

### ESP32-WROOM-32（ESP32-D0WD-V3）

| 引脚名称 | ESP32引脚 | 功能说明 | 是否外部可用 |
|----------|-----------|----------|--------------|
| WIFI_RXD | GPIO16 | WIFI接收数据 | 否（内部连接） |
| WIFI_TXD | GPIO17 | WIFI发送数据 | 否（内部连接） |
| WIFI_CLK | GPIO18 | WIFI时钟 | 否（内部连接） |
| WIFI_CS | GPIO19 | WIFI片选 | 否（内部连接） |
| WIFI_RST | GPIO20 | WIFI复位 | 否（内部连接） |
| WIFI_EN | GPIO21 | WIFI使能 | 否（内部连接） |

### ESP32-S3-WROOM-1

| 引脚名称 | ESP32-S3引脚 | 功能说明 | 是否外部可用 |
|----------|-------------|----------|--------------|
| WIFI_RXD | GPIO16 | WIFI接收数据 | 否（内部连接） |
| WIFI_TXD | GPIO17 | WIFI发送数据 | 否（内部连接） |
| WIFI_CLK | GPIO18 | WIFI时钟 | 否（内部连接） |
| WIFI_CS | GPIO19 | WIFI片选 | 否（内部连接） |
| WIFI_RST | GPIO20 | WIFI复位 | 否（内部连接） |
| WIFI_EN | GPIO21 | WIFI使能 | 否（内部连接） |

> **重要提示**：以上引脚为 ESP32 芯片内部连接，用户无需外部接线。请勿将这些引脚用于其他用途，以免干扰 WIFI 功能。

## 天线连接

### ESP32-WROOM-32 模块

```
ESP32-WROOM-32 模块
├── IPEX天线接口（U.FL）
│   └── 连接外部天线（可选）
└── 板载PCB天线
    └── 无需额外接线（默认使用）
```

### ESP32-S3-WROOM-1 模块

```
ESP32-S3-WROOM-1 模块
├── IPEX天线接口（U.FL）
│   └── 连接外部天线（可选）
└── 板载PCB天线
    └── 无需额外接线（默认使用）
```

#### 天线选择建议

| 场景 | 推荐方案 | 说明 |
|------|----------|------|
| 室内短距离 | 板载PCB天线 | 成本低，无需额外组件 |
| 室外/远距离 | 外部天线 + IPEX | 信号更强，传输距离更远 |
| 金属外壳设备 | 外部天线 + SMA连接线 | 避免金属屏蔽影响信号 |

## 电源要求

### 电压要求

| 参数 | 最小值 | 推荐值 | 最大值 |
|------|--------|--------|--------|
| 输入电压 | 3.0V | 3.3V | 3.6V |

### 电流要求

| 工作模式 | 典型电流 | 峰值电流 |
|----------|----------|----------|
| 待机（STA模式） | 15mA | 50mA |
| 传输数据（STA模式） | 80mA | 200mA |
| SoftAP模式 | 100mA | 250mA |
| 扫描模式 | 150mA | 300mA |

### 电源设计建议

```
推荐电源电路：
┌─────────────────────────────────────────────────────┐
│                  电源输入（5V）                       │
│                        │                             │
│                        ▼                             │
│                  稳压器（AMS1117-3.3）                │
│                        │                             │
│                        ▼                             │
│              ┌──────────────────┐                   │
│              │   100nF电容      │  去耦电容          │
│              └──────────────────┘                   │
│                        │                             │
│                        ▼                             │
│                   ESP32 VDD3P3                       │
└─────────────────────────────────────────────────────┘
```

> **注意**：WIFI 模块在传输数据时电流变化较大，建议使用输出电流 >= 500mA 的稳压器，并在电源引脚附近放置足够的去耦电容（至少 100nF）。

## 接线可用性检查

### GPIO 引脚使用情况

此组件**不占用任何外部 GPIO 引脚**，所有 WIFI 相关引脚均为芯片内部连接。

### 注意事项

1. **避免引脚冲突**：虽然此组件不使用外部 GPIO，但在设计硬件时需注意：
   - 不要将 GPIO16-21 用于其他外设（这些引脚内部连接到 WIFI 模块）
   - 部分开发板可能将这些引脚引出，需确认用途

2. **射频干扰**：
   - WIFI 模块工作在 2.4GHz 频段
   - 避免在天线附近放置高频电路
   - 保持天线与其他元件的距离 >= 5mm

3. **接地要求**：
   - 提供良好的接地平面
   - 天线附近的接地应完整
   - 减少接地回路面积

## 典型应用

### 应用场景

- 物联网设备联网
- 智能家居控制
- 远程数据采集
- OTA 固件升级
- 云端通信

### 连接流程

```
设备启动
    │
    ▼
检查 NVS 中是否有保存的 WIFI 配置
    │
    ├── 有配置 ──► 尝试连接 WIFI
    │                  │
    │                  ├── 连接成功 ──► 启动 NTP 时间同步
    │                  │                  │
    │                  │                  ▼
    │                  │              正常运行
    │                  │
    │                  └── 连接失败 ──► 重试（最多 N 次）
    │                                    │
    │                                    ├── 重试成功 ──► 启动 NTP 时间同步
    │                                    │
    │                                    └── 重试 N 次失败 ──► 进入配置模式
    │
    └── 无配置 ──► 进入配置模式
                      │
                      ├── 手机配置模式：启动 SoftAP + Web 服务器
                      │
                      └── 屏幕配置模式（预留）
```

## 故障排查

### 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 无法扫描到 WIFI | 天线未连接或损坏 | 检查天线连接，更换天线 |
| 连接失败 | 密码错误或网络不可用 | 重新配置密码，检查网络 |
| 信号弱 | 距离过远或障碍物遮挡 | 靠近路由器，使用外部天线 |
| 频繁断开 | 电源不稳定 | 使用更大电流的电源，增加去耦电容 |
| SoftAP 无法连接 | 信道冲突 | 更换信道（建议使用 1、6、11） |

### 调试方法

1. **查看串口日志**：
   ```bash
   idf.py monitor
   ```
   搜索 `wifi_manager` 标签查看相关日志

2. **查询连接状态**：
   ```c
   wifi_status_t status;
   wifi_get_status(&status);
   ```

3. **检查 NVS 存储**：
   ```bash
   idf.py erase-flash  # 清除所有 NVS 数据
   ```

4. **使用手机配置界面**：
   - 连接 ESP32 热点
   - 访问 `http://192.168.4.1`
   - 重新配置 WIFI

## 安全注意事项

1. **密码安全**：WIFI 密码存储在 NVS 中，建议对敏感应用进行加密存储
2. **网络安全**：SoftAP 模式下默认密码为 `12345678`，建议修改为强密码
3. **固件安全**：建议启用 OTA 签名验证，防止恶意固件升级
